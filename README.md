# ong-esperan-a-
Profissional focado em tecnologia e inovação, com experiência em análise de dados e resolução de problemas complexos.
## Arquivos do projeto

- `index.html` — página inicial, com apresentação da ONG, seção “Quem Somos” e contato.
- `cadastro.html` — formulário com campos de dados pessoais e validação HTML5.
- `style.css` — estilos e layout responsivo das páginas.
- `equipe.jpg` — imagem utilizada na seção “Quem Somos”.

## Como visualizar

1. Salve todos os arquivos na mesma pasta.
2. Coloque a imagem `equipe.jpg` nessa pasta.
3. Abra o arquivo `index.html` em um navegador.
4. Use o link “Cadastro” para acessar o formulário.

## Validação do formulário

O formulário utiliza validação nativa do HTML5. Telefone e CPF devem ter 11 números, e o CEP deve ter 8 números.

Os valores exibidos nos campos são exemplos fictícios. O CPF `22222222222` e o CEP `11111111` servem apenas como exemplos de formato e não são documentos válidos.
